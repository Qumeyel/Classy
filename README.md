🚀 项目名称

Classy，西师课表，是一个基于webview的课表。

📖 项目介绍

这个项目主要用于广西师大易班的课表。

希望通过这个项目改善师大学子的课程查询体验，提升学习效率。

由Qumeyel与LMSLuos制做。欢迎反馈！

✨ 项目功能

- 📌 功能一：自动深色模式
- 📌 功能二：课堂时间显示

🛠️ 使用技术

- 编程语言：Python,Javascript
- 开发工具：VScode
- 使用框架：python-flet

📂 项目结构

项目名称/<br>

└── assets/icon.png<br>

🚀 如何使用

1. 下载或克隆项目。
2. 安装所需环境(python,flet)
3. 打包成apk安装到手机使用。
